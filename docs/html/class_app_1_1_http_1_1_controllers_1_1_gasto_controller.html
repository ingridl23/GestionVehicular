Detailed Description

Controlador encargado de la gestión de gastos asociados a viajes.

Permite:

  • Previsualizar el gasto estimado de un viaje
  • Generar y persistir un gasto
  • Consultar gasto individual por viaje
  • Listar todos los gastos
  • Obtener estadísticas generales

La lógica de negocio se delega a GastoService. La autorización se gestiona mediante Policies de Laravel.

Fórmula de cálculo del gasto: importe = litros_consumidos * valor_litro
