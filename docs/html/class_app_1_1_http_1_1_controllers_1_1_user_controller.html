Detailed Description

Controlador encargado de la gestión integral de usuarios del sistema.

Funcionalidades principales:

  • Dashboard administrativo y operativo
  • Gestión completa de usuarios (CRUD)
  • Gestión de roles y dependencias
  • Gestión de perfil propio
  • Habilitar / deshabilitar usuarios

Implementa control de acceso mediante Gates y Roles (Spatie). Integra notificaciones ante cambios de rol o dependencia.
